# DNN Visualizer

A cinematic desktop neural network visualizer built with Python and PySide6. Explore forward propagation, backpropagation, and decision boundaries in a polished application window.

## Features

- Interactive architecture controls and training panel
- Live dataset explorer with XOR, moons, circles, spiral, and Iris examples
- Animated network layout with weight and activation shading
- Real-time loss, accuracy, and gradient norm tracking
- Decision boundary visualization for classification learning
- Guided lesson mode with step-by-step AI explanations for beginners
- Clean, polished interface with clear panels and educational tooltips
- Educational, modulable neural network core with full forward/backward propagation

## Setup

1. Create and activate the virtual environment:
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```
2. Install dependencies:
   ```powershell
   python -m pip install -r requirements.txt
   ```
3. Run the application:
   ```powershell
   python main.py
   ```

## Notes

This repository has been rebuilt as a Python desktop application. The UI is designed to feel immersive and educational while running neural network training and visualization in real time.
